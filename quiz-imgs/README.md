# quiz-imgs フォルダ

シルエットクイズ用の画像を入れてください。

## ファイル名のルール

| ファイル名 | 内容 |
|-----------|------|
| `apple-shadow.png`    | リンゴ　シルエット（黒い影） |
| `apple-trick.png`     | リンゴ　ひっかけ（カバの絵） |
| `apple-answer.png`    | リンゴ　正解（リンゴの絵） |
| `penguin-shadow.png`  | ペンギン　シルエット |
| `penguin-trick.png`   | ペンギン　ひっかけ（ネコの絵） |
| `penguin-answer.png`  | ペンギン　正解 |
| `elephant-shadow.png` | ゾウ　シルエット |
| `elephant-trick.png`  | ゾウ　ひっかけ（とのさまの絵） |
| `elephant-answer.png` | ゾウ　正解 |
| `squid-shadow.png`    | イカ　シルエット |
| `squid-trick.png`     | イカ　ひっかけ（おじさんの絵） |
| `squid-answer.png`    | イカ　正解 |

## 画像がない場合

画像ファイルが見つからない場合は絵文字で自動的に表示されます。
